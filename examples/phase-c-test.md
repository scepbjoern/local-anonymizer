# Fiktiver Testtext für Phase C

Diese Datei enthält ausschliesslich erfundene Inhalte. Sie dient dazu, die
optionale Erkennung von Rollen sowie die verbesserte Erkennung und Filterung
von Personenbezeichnungen in der Benutzeroberfläche zu prüfen.

## Personen

Max Beispiel bespricht den Entwurf mit Julia Muster.
Julia Muster sendet die überarbeitete Fassung an Max Beispiel.

Die Autoren prüfen danach die Dokumentation. Die Vorgesetzte bestätigt den
Entwurf, während der Sachbearbeiter die nächsten Schritte dokumentiert.
Eine reisende Person reicht später noch eine kurze Notiz ein.

## Rollen und Funktionsbezeichnungen

Der CEO von Beispielwerk entscheidet über die Freigabe.
Die CFO, Erika Muster, prüft den fiktiven Finanzbericht.
Der Leiter Prozessmanagement koordiniert die Einführung.
Ein Bereichsleiter erhält anschliessend eine Kopie des Berichts.

## Weitere fiktive Begriffe

Im Beispiel wird das interne System NimbusFlow verwendet. Die Ergebnisse
werden anschliessend im fiktiven ClaimsBoard kontrolliert.

Diese Begriffe können bei Bedarf testweise als Glossar-Einträge angelegt
werden: CEO, CFO und Leiter Prozessmanagement.
